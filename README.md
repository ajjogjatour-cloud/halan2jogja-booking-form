# Halan2Jogja Booking Form

Form booking digital untuk **Halan2Jogja Tour**, dibuat dalam satu file HTML (tanpa backend/server). 

Customer mengisi data perjalanan, lalu sistem otomatis menyusun pesan booking card dan mengirimkannya langsung ke WhatsApp admin.

## Fitur
- Form input: Nama, Nomor WhatsApp, Tanggal, Lokasi Jemput
- Pilihan durasi wisata (4–12 jam) dalam bentuk pill selector
- Pilihan unit kendaraan (Toyota Calya, Avanza New, Reborn, Hiace)
- Tujuan wisata bebas isi (textarea)
- Validasi: tombol kirim memastikan semua data terisi
- Klik "Kirim Booking via WhatsApp" langsung membuka chat WhatsApp ke admin dengan format booking card otomatis
- Desain mobile-first (rasio 9:16), tema dark monochrome dengan aksen hijau khas brand

## Cara pakai
1. Buka `booking_halan2jogja.html` di browser (atau host via GitHub Pages)
2. Isi semua field
3. Klik tombol kirim → otomatis terbuka WhatsApp dengan pesan siap kirim

## Teknologi
- HTML, CSS, JavaScript (vanilla, tanpa dependency/framework)
